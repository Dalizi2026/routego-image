# Routego Image

Routego Image 是一个面向 Codex 的本地个人图像插件：通过用户配置的 OpenAI 兼容图像服务完成生图、参考图生成、单图/多图编辑，并在本机 Studio 中管理图库、设置和任务结果。

当前发布版本：**v1.0.5**（插件包版本 `1.0.5+codex.20260802`）。

Windows 使用独立插件包：**Routego Image for Windows v1.0.0**（`routego-image-windows`）。它与 Mac 版隔离本地配置、图库与运行时数据，避免误读取彼此的供应商信息。每次先以 Mac 主版完成验证，再同步共享核心并单独通过 Windows 安装冒烟测试后发布 Windows 维护版。

## 核心能力

- 本地 Studio：配置服务商、模型、默认参数、响应等待上限和图库位置。
- 图像生成与编辑：支持参考图、目标图、不变量约束、常用尺寸、比例、质量与 PNG/JPEG 输出。
- 图库：保存任务参数与成品，提供筛选、排序、文件夹和下载操作。
- 透明背景：自动模式会在当前渠道选择受控色键去背；色键模式输出真实 Alpha PNG。原生透明仅在渠道已经验证支持时使用，避免把不可靠的本地回退误报为成功。

## 版本更新

### v1.0.5

- 完善透明背景工作流：自动模式和色键模式使用规范绿色背景、容差识别和边缘去绿，输出真实透明 PNG。
- 增加本地 ONNX 背景分割运行时及资源完整性校验；未验证支持原生 Alpha 的渠道不再直接发送透明参数。
- 原生透明回退结果会明确标记为需要人工复核，不再把边缘质量不足的结果当作成功交付。
- 修复后台任务完成后的图库可见性与发布包校验，更新插件包、许可清单和安装冒烟检查。

### Windows v1.0.0

- 新增独立 Windows 插件包、启动入口和本地数据目录，不影响既有 Mac 安装及配置。
- 对 Windows 的异常图像响应记录安全协议诊断（编码、内容类型、长度与解析阶段），不保存服务商原始正文、接口地址或密钥。
- 增加 Windows 云端构建、可复现打包和临时安装启动验证。

### v1.0.4

- 完善 Studio 图库体验：筛选、分页、排序、卡片详情、下载与响应式界面持续优化。
- 增加渠道能力证据展示与常用参数的真实场景验证，减少不兼容参数的误用。
- 改进本地服务、任务保存和图库读取的稳定性。

### v1.0.3

- 将 Studio 中配置的图像响应等待上限同步到插件执行链路，避免聊天端与 Studio 设置不一致。
- 修复长时生图任务的状态处理与恢复逻辑，改善任务结果的保存可靠性。

### v1.0.2

- 增加 Codex 对话附件工作流：单图编辑、多参考图生成和目标图不变量约束。
- 增强 OpenAI 兼容中转的图像输入与输出处理，支持在对话内完成真实图像任务。

### v1.0.1

- 建立可用的 Routego Image 1.0 基础：本地配置、OpenAI 兼容图像调用、默认参数与本地图像保存。
- 引入 Studio、图库和可验证的插件打包流程，为后续图像编辑与管理功能提供基础。

## 开发与验证

```bash
pnpm install
pnpm typecheck
pnpm build:plugin
pnpm verify:plugin
```

插件构建输出在 `.routego-plugin-build/routego-image`。运行测试或构建前请勿提交 API Key、用户图片、图库文件和本地缓存。

详细产品与开发规划见 [routego-image-1.0-plan.md](routego-image-1.0-plan.md)。
